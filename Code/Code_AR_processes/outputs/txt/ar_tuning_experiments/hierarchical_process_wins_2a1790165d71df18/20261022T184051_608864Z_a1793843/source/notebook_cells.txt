# CELL introduction (markdown)
# Final AR tuning — process-level wins

This notebook contains one final tuning experiment: **100 Jones-sampled AR(3)
processes × 100 realizations per process** by default. It compares random and
$e_1$ starting directions with absolute and diameter-normalized initial steps.
Run every cell from top to bottom. The process and realization counts are
editable in the experiment settings. [Experiment runner](../ar_tools/tuning.py).

For each process, average achieved minimum widths across realizations before
comparing all four configuration grids together. Final selection uses
**process-win counts**, with full credit for co-winners. The matrix and the
half-life curves show the same counts; the curves reuse the completed fits.

### Automatic exports

Both figures are displayed and saved automatically as **PDF and PNG** under
`../outputs/pdfs/ar_tuning_experiments/hierarchical_process_wins_<run-id>/`
and the corresponding `../outputs/images/` folder. No tables or text logs are
displayed; calculation errors still propagate.

Each run also creates a timestamped **UTF-8 `.txt` archive** under
`../outputs/txt/ar_tuning_experiments/hierarchical_process_wins_<run-id>/<timestamp>/`.
It preserves settings, configuration grids, coefficients, exact seeds and
starting directions, retained series and point clouds, individual fit results,
process means and co-winners, final rankings, and unrounded figure data.
Tables use tab-separated columns and full floating-point precision. The archive
includes a README, manifest, completion status, environment versions and source
snapshots. Individual fits are written one process at a time; an interruption
retains completed exports and an incomplete status. Iteration trajectories and
discarded burn-in samples are not exported. [Export implementation](../ar_tools/tuning_exports.py).

# CELL settings-description (markdown)
### Optimizer settings and tuning grids

The grid is $H\in\{2,5,10,20,50,100,200,1000\}$ and
$c\in\{0.1,0.2,\ldots,0.9\}$, with $\beta=2^{-1/H}$.
Each scale gives $\gamma_0=c$ for absolute steps or $\gamma_0=c/L$ for
diameter-normalized steps, where $L$ is the empirical point-cloud diameter.
There are 72 configurations per start/step variant and 288 in total.
[Grid and step rules](../ar_tools/tuning.py).

The experiment uses a **2,000-iteration cap and patience 200**.
`improvement_tolerance=0` records every strictly smaller width. The separate
**`delta=1e-8`** resets patience only after a cumulative decrease of at least
`delta` from the previous patience reference; that reference then becomes the
current best width. Stop after 200 consecutive iterations without such a
decrease, or at the iteration cap. Set `delta=0` to reset patience after every
strict improvement. Each descent uses one start, with stationarity checks and
restarts disabled. [Stopping implementation](../ar_tools/descent.py).

Each path has $T=500$ retained observations and uniform innovations on $[-1,1]$,
after 2,000 discarded burn-in observations. Seeds and burn-in are explicit
experimental settings. The process-win tolerance is configured separately in
Section 2 and applies **after averaging widths within each process**.
[Simulation](../ar_tools/functions.py), [paired runner](../ar_tools/tuning.py).

if (isinstance(delta, (bool, np.bool_))
        or not isinstance(delta, (int, float, np.integer, np.floating))
        or not np.isfinite(delta) or delta < 0):
    raise ValueError("delta must be a finite nonnegative number.")


# CELL hierarchical-mean-width-description (markdown)
## 2. Final tuning: process-level wins from 100 processes × 100 realizations

For each of 100 Jones-sampled causal AR(3) coefficient vectors, generate 100 independent innovation paths. All configurations and all four start/step variants use the same paths. Draw 100 random starting directions once; reuse direction r for realization r of every process and every random-start configuration. Coefficient draws, innovations and starting directions have separate seeded streams. The e1 variants always start at e1. [Sampler](../ar_tools/functions.py), [paired fixed-process runner](../ar_tools/tuning.py).

For each process and configuration, first average the achieved minimum widths across all 100 realizations. Compare these unrounded means across all four grids together. Every configuration within `hierarchical_mean_win_tolerance=1e-8` of that process's lowest mean receives +1. The final matrix cells show process-win counts from 0 to 100. Co-winners receive full points, so total credits may exceed 100. This counts process-level wins; it does not select by the overall average across all 10,000 realizations.

Red outlines mark every tied overall leader by final count. Light grey outlines mark every tied positive leader within each panel, using the same global-contest counts; grey is inset when red also applies. Entirely zero panels are labelled and receive no grey outlines. No MAE or maximum-iteration annotations are displayed.

Run the setup cells above, then every cell in this section. Both experiment sizes are editable below. Defaults use 100 x 100 x 288 = 2,880,000 descents. Individual fit rows are written to per-process `.txt` files before being released from memory. Process-level means and seed/start metadata remain in memory, keeping memory bounded. Settings, coefficients, starts, retained series/clouds, all individual fits, per-process means and co-winners, final rankings, leaders and figure matrices are exported to the timestamped text archive. The matrix and the process-win line plot below are displayed and saved as PDF/PNG; no tables are displayed. The full experiment is configured but has not been executed here.

# CELL hierarchical-mean-width-run (code)
def hierarchical_tune_one_process(model_id, phi, innovation_root_seed):
    """Average all realizations first, then award process-level co-winner credits."""
    frames = []
    reference_cases = None
    pairing_columns = [
        "replication", "T", "process_seed", "phi_1", "phi_2", "phi_3",
        "population_minimum_width", "empirical_true_direction_width",
    ]
    for initialization, directions in (
        ("random_shared_bank", hierarchical_start_bank), ("e1", hierarchical_e1),
    ):
        for step_rule in ("absolute", "diameter_normalized"):
            experiment = tuning_tools.tune_fixed_ar_realizations(
                phi, T, directions, scale_grid, half_life_grid,
                replications=hierarchical_realizations_per_process,
                process_seed=innovation_root_seed, burnin=burnin,
                iterations=max_iterations, patience=patience,
                improvement_tolerance=improvement_tolerance, delta=delta,
                optimizer_seed=optimizer_seed, step_rule=step_rule,
                stationarity_check=False, max_restarts=0, coefficient_diagnostics=False,
                n_jobs=hierarchical_n_jobs, progress=False, summarize=False,
            )
            cases = pd.DataFrame(experiment["cases"]).sort_values("replication").reset_index(drop=True)
            assert len(cases) == hierarchical_realizations_per_process
            assert cases["process_seed"].is_unique
            if reference_cases is None:
                reference_cases = cases.copy()
            pd.testing.assert_frame_equal(cases[pairing_columns], reference_cases[pairing_columns], check_exact=True)
            expected_starts = (hierarchical_start_bank if initialization == "random_shared_bank"
                               else np.tile(hierarchical_e1, (hierarchical_realizations_per_process, 1)))
            np.testing.assert_allclose(cases[hierarchical_start_columns], expected_starts, atol=1e-15, rtol=0)
            runs = pd.DataFrame(experiment["results"]).assign(initialization=initialization)
            assert len(runs) == hierarchical_realizations_per_process * hierarchical_grid_size
            assert not runs.duplicated(["candidate_id", "replication"]).any()
            assert np.isfinite(runs["minimum_width"]).all()  # Do not silently omit failed runs.
            assert runs["selected_start"].eq(1).all()
            assert runs["total_evaluations"].between(1, max_iterations).all()
            np.testing.assert_array_equal(runs[["phi_1", "phi_2", "phi_3"]], np.tile(phi, (len(runs), 1)))
            np.testing.assert_array_equal(
                runs[hierarchical_start_columns].to_numpy(),
                cases.set_index("replication").loc[runs["replication"], hierarchical_start_columns].to_numpy(),
            )
            # Persist individual widths before averaging or releasing this process.
            HIERARCHICAL_TEXT_ARCHIVE.save_experiment(
                f"processes/process_{model_id:03d}/{initialization}_{step_rule}", experiment,
                input_group=f"process_{model_id:03d}", burnin=burnin,
                context={"model_id": model_id, "initialization": initialization},
            )
            frames.append(runs)
    all_runs = pd.concat(frames, ignore_index=True)
    means = all_runs.groupby(
        ["initialization", "step_rule", "candidate_id", "step_value", "half_life", "beta"], as_index=False,
    ).agg(mean_achieved_width=("minimum_width", "mean"), realization_count=("replication", "size"))
    assert len(means) == 4 * hierarchical_grid_size
    assert means["realization_count"].eq(hierarchical_realizations_per_process).all()
    process_best = means["mean_achieved_width"].min()
    means = means.assign(
        model_id=model_id, process_best_mean=process_best,
        process_win=means["mean_achieved_width"].le(process_best + hierarchical_mean_win_tolerance),
    )
    # Retain small summaries and seed/start records, rather than all raw descents.
    seed_records = reference_cases[pairing_columns + hierarchical_start_columns].assign(model_id=model_id)
    HIERARCHICAL_TEXT_ARCHIVE.save_table(f"processes/process_{model_id:03d}/mean_widths_and_wins", means)
    HIERARCHICAL_TEXT_ARCHIVE.save_table(f"processes/process_{model_id:03d}/realization_metadata", seed_records)
    HIERARCHICAL_TEXT_ARCHIVE.checkpoint(f"Process {model_id} completed and saved; other processes may remain.")
    return means, seed_records

with capture_output():
    hierarchical_mean_frames = []
    hierarchical_seed_frames = []
    for hierarchical_model in hierarchical_models.itertuples(index=False):
        hierarchical_phi = np.array([
            getattr(hierarchical_model, f"phi_{j+1}") for j in range(p)
        ])
        hierarchical_means, hierarchical_seeds = hierarchical_tune_one_process(
            int(hierarchical_model.model_id), hierarchical_phi,

        )
        hierarchical_mean_frames.append(hierarchical_means)

    hierarchical_realization_metadata = pd.concat(hierarchical_seed_frames, ignore_index=True)
    assert hierarchical_realization_metadata["process_seed"].is_unique
    assert not hierarchical_process_means.duplicated(["model_id", "initialization", "candidate_id"]).any()
    hierarchical_ranking = hierarchical_process_means.groupby(
        ["initialization", "step_rule", "candidate_id", "step_value", "half_life", "beta"], as_index=False,
    ).agg(process_wins=("process_win", "sum"), process_count=("model_id", "nunique"))
    hierarchical_ranking["process_wins"] = hierarchical_ranking["process_wins"].astype(int)
    hierarchical_ranking = hierarchical_ranking.sort_values(
        ["process_wins", "initialization", "step_rule", "step_value", "half_life"],
        ascending=[False, True, True, True, True],
    ).reset_index(drop=True)
    assert hierarchical_ranking["process_count"].eq(hierarchical_number_of_processes).all()
    assert hierarchical_ranking["process_wins"].between(0, hierarchical_number_of_processes).all()
    assert hierarchical_ranking["process_wins"].sum() == hierarchical_process_means["process_win"].sum()
    assert hierarchical_process_means.groupby("model_id")["process_win"].any().all()
    hierarchical_best_count = int(hierarchical_ranking["process_wins"].max())
    hierarchical_leaders = hierarchical_ranking.loc[

    HIERARCHICAL_TEXT_ARCHIVE.save_table("all_process_mean_widths_and_wins", hierarchical_process_means)
    HIERARCHICAL_TEXT_ARCHIVE.save_table("all_realization_metadata", hierarchical_realization_metadata)
    HIERARCHICAL_TEXT_ARCHIVE.save_table("process_win_ranking", hierarchical_ranking)
    HIERARCHICAL_TEXT_ARCHIVE.save_table("highest_process_win_configurations", hierarchical_leaders)
    HIERARCHICAL_TEXT_ARCHIVE.save_table("per_process_co_winners", hierarchical_process_means.loc[
        hierarchical_process_means["process_win"]
    ])
    HIERARCHICAL_TEXT_ARCHIVE.save_document("selection_rule", {
        "score": "mean achieved minimum width within each process",
        "reference": "all four start/step grids together",
        "absolute_co_winner_tolerance": hierarchical_mean_win_tolerance,
        "full_credit_for_ties": True, "highest_process_win_count": hierarchical_best_count,
        "total_process_win_credits": int(hierarchical_ranking["process_wins"].sum()),
    })
