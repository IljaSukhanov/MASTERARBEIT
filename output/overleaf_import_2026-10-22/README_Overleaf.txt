OVERLEAF UPLOAD PACKAGE

Upload overleaf_thesis_2026-10-22.zip using New Project > Upload Project.
Select main.tex as the main document and pdfLaTeX as the compiler.

This package contains the thesis source files and required figures, without
simulation notebooks or result archives. The original folder hierarchy is
retained for existing chapter and figure references. main.tex is a small entry
point that adds the original source directory to the input search path.
The root bibliography files support compilation from the project root.

All copied thesis sources are byte-for-byte identical to the originals.
A local pdfLaTeX/latexmk build succeeded and produced 106 pages.
The source currently has one unresolved reference and one duplicate label;
these pre-existing source issues were preserved.

For continuing GitHub synchronization, use a dedicated repository containing
this package rather than the full research repository. Overleaf limits each
project to 2000 files:
https://docs.overleaf.com/getting-started/free-and-premium-plans/plan-limits
